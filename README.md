# Big Data. Blockchain
To get started developing if you use Nix just run: `nix develop`, it will
install all required dependencies for both building and development even if you don't have go installed on your computer. To build and run project: `nix run`.

You can also install [nix-direnv](https://github.com/nix-community/nix-direnv) to automagically enter development environment on cd into project directory.

Otherwise just use default go commands.
